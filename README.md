# 토익 30일 단어장

암기 마스터(ankimaker.com)의 토익 폴더에 정리한 DAY 01–30 영단어 1,641개로 만든 단어 학습 페이지입니다.
`index.html` 하나로 동작하며, 브라우저에서 바로 열면 됩니다.

## 기능

- **Day 목록**: LC 필수 어휘 · 동사 · 명사 · 형용사 · 부사/전치사 · RC 지문 유형별로 Day를 묶어 보여 주고, Day마다 외운 단어 수와 최고 시험 점수를 표시합니다.
- **단어 목록**: 뜻 앞에 품사 표시(n · v · a · ad · prep · conj · phr). LC 필수 어휘(Day 01–10)는 뜻을 한 줄씩, 동사 → 명사 → 형용사 순으로 보여 줍니다.
  - 뜻 가리기 / 영어 가리기, 발음 듣기(▶), 내 메모(✎), 별표(☆)와 별표만 보기
  - 설명이 있는 단어는 박스를 눌러 펼치고 다시 눌러 접습니다.
  - 시험에서 맞힌 단어는 영어 단어가 연두색으로 바뀝니다.
- **플래시카드**: 뒤집기, 섞기, 아직 못 맞힌 단어만 보기
- **시험**: Day 범위와 문항 수를 골라 네 가지 유형으로 봅니다.
  - 영어 → 뜻 고르기, 뜻 → 영어 고르기 (A–D 객관식)
  - 영어 보고 뜻 쓰기: 품사별 입력 칸, 칸마다 채점, ‘정답으로 인정’
  - 뜻 보고 철자 쓰기
- **오답노트**: 틀린 단어와 틀린 횟수를 모아 객관식 · 뜻 쓰기 · 철자 오답 시험을 봅니다.

## 저장 방식

외운 단어, 오답노트, 최고 점수는 브라우저(localStorage)에 저장됩니다.
claude.ai 아티팩트로 열면 메모와 별표는 계정에 저장되고, 이 파일을 직접 열면 메모와 별표도 브라우저에 저장됩니다.

## 발음

브라우저에 설치된 음성(Web Speech API)을 씁니다. 영어 음성이 없는 기기에서는 안내 문구가 나옵니다.
Chrome이나 Edge에서는 설치 없이 미국 영어 음성으로 들을 수 있습니다.
